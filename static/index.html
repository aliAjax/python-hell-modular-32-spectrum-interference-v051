无线电频谱干扰调查与协调

使用 JSON API 管理保护时段、干扰事件、来源记录、停用授权与处置动作。

GET  /health
GET  /api/state
POST /api/items
POST /api/items/{id}/sources
POST /api/items/{id}/actions
GET  /api/items/{id}/audit
POST /api/windows
POST /api/windows/{id}/adjust
GET  /api/windows

写请求带 expected_version 做先写入者胜的并发控制；带 X-Request-Id 可在失败后按原编号重试，已完成的授权与审计不重复。保护时段变更时，覆盖范围内未结事件自动退回复核，停用授权失效，需协调员 reconfirm 重新确认。
