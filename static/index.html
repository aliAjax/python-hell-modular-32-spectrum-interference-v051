无线电频谱干扰调查与协调

使用 JSON API 创建干扰事件、记录来源、定位、执行处置动作，并设置保护时段。

写操作可携带 X-Request-Id 头用于幂等重试；处置动作需携带 expected_version 进行乐观并发控制。

GET  /health
GET  /api/state
GET  /api/items
POST /api/items
POST /api/items/{id}/sources
POST /api/items/{id}/actions
GET  /api/items/{id}/audit
GET  /api/protection-periods
POST /api/protection-periods
GET  /api/protection-periods/{id}
POST /api/protection-periods/{id}/actions
